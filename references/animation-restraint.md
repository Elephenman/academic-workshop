# 学术动画克制规则

> 来源：花叔Design `references/animation-best-practices.md` + `animation-pitfalls.md`
> 蒸馏日期：2026-05-04
> 蒸馏方式：提取学术场景适用规则，删除商业/发布会/营销场景内容

---

## 学术PPT动画铁律

**学术PPT几乎不用动画**。这条规则的底层逻辑：

1. 组会PPT是**信息传递工具**，不是视觉秀场
2. 导师和同组关心的是**你的数据和方法**，不是你的PPT特效
3. 动画在投影场景经常翻车（延迟/卡顿/不同设备表现不一致）
4. 学术场景的"高级感"来自**克制**，不是来自运动

---

## 唯一允许的动画

| 动画类型 | 使用场景 | 参数 |
|---------|---------|------|
| **Fade切换** | 页间切换 | 持续时间≤300ms |
| **Appear** | 内容出现 | 无动画，直接出现 |

> 就这两种。没有第三种。

---

## 禁止的动画（学术场景）

| 动画类型 | 为什么禁止 |
|---------|-----------|
| Fly-in / Fly-out | 像PPT模板，学术感-100 |
| Spin / Rotate | 除非展示3D蛋白结构 |
| Bounce / 弹跳 | 永远不合适 |
| 逐字出现 | 浪费时间，观众等不及 |
| 自动播放 | 组会PPT由演讲者控制节奏 |
| Morph变形 | 商业演示用，学术不需要 |
| 路径动画 | 干扰信息传达 |
| 缩放动画 | 投影场景表现不可控 |

## 从花叔Design动画规则中保留的思维

虽然学术PPT几乎不用动画，但以下**设计思维**适用于静态PPT：

1. **Slow-Fast-Boom-Stop → 信息节奏**
   - 学术版：封面(慢)→背景(快)→方法(快)→**结果(慢/停顿)**→讨论(快)→总结(慢)
   - 结果页是视觉高潮，值得用breathing节奏（大图+留白+一句解读）

2. **焦点切换 → 信息层级**
   - 不用动画实现，用**排版层级**实现：标题大+正文小+注释淡
   - 关键数据用accent色突出，辅助信息用muted灰

3. **留白 = 礼让观众**
   - 不需要在动画里加0.5s停顿——**直接在页面设计里留白**
   - 结果页80%画布给Figure，20%给解读文字

4. **克制 > 炫技**
   - 学术PPT的"120%精致"放在：数据图表的精确性、引用格式的严谨性、色值的一致性
   - 不是放在：页面过渡特效、元素入场动画

---

## 如果用户坚持要动画

告诉用户：

> "学术PPT默认无动画（仅fade切换）。动画在投影场景表现不稳定，且不影响内容传达。如果确实需要，我可以给特定页加Appear效果——但建议先试无动画版本。"

如果用户确认，只加Fade切换（≤300ms），不加其他任何动画。
