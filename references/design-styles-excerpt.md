## 01. Pentagram - Michael Bierut风格

**哲学**：字体即语言，网格即思想

**核心特征**：
- 极度克制的颜色（黑白+1个品牌色）
- 瑞士网格系统的现代演绎
- 字体排印作为主要视觉语言
- 负空间的战略性使用（60%+留白）

**学术适配说明**：
- 最适合学术答辩/论文汇报PPT
- 品牌色可替换为浙大蓝#003366或论文主题色
- 字体层级：衬线标题+系统正文，避免全sans-serif
- 关键结果页用60%+留白，一张大Figure+一句解读

**提示词DNA**：
```
Pentagram/Michael Bierut style:
- Extreme typographic hierarchy, serif display + sans body
- Swiss grid with precise mathematical spacing
- Black/white + one accent color (university blue)
- 60%+ whitespace ratio
- Data visualization as primary decoration
```

## 04. Fathom Information Design - 科学叙事

**哲学**：每一个像素都必须承载信息

**核心特征**：
- 科学期刊的严谨+设计的优雅
- 定量数据的精确可视化
- 冷静的专业色调（灰、海军蓝）
- 注释与引用系统的设计化

**学术适配说明**：
- 最适合生信/数据驱动论文汇报
- 图表设计优先级最高——不要装饰性元素
- 引用系统（脚注/参考文献）需视觉化处理
- 配色：海军蓝#1A3A5C + 中性灰 + 单一accent

**提示词DNA**：
```
Fathom Information Design style:
- Scientific journal aesthetic meets modern design
- Precise data visualization (charts, timelines, scatter plots)
- Neutral scheme (grays, navy, one highlight color)
- Footnote/citation design integrated into layout
- Information density without clutter
```

## 10. Müller-Brockmann传承 - 瑞士网格纯粹主义

**哲学**：客观性即美

**核心特征**：
- 数学精确的网格系统（8pt基线）
- 绝对的左对齐或居中
- 单色或双色方案
- 功能主义至上

**学术适配说明**：
- 最适合方法流程页和讨论页
- 流程图/步骤条用8pt网格对齐
- 方法页：步骤编号+简洁描述，不搞花哨图标
- 讨论页：2列列表或简洁表格

**提示词DNA**：
```
Josef Müller-Brockmann Swiss modernism:
- Mathematical grid system (8pt baseline)
- Strict alignment (flush left or centered)
- Two-color maximum (black + one accent)
- No decorative elements
- Timeless, objective aesthetic
```

## 17. Taktram - 日式思辨设计

**哲学**：技术是思考的媒介

**核心特征**：
- 概念原型的优雅
- 柔和的科技感（圆角、柔和阴影）
- 图表即艺术
- 谦逊的精致

**学术适配说明**：
- 适合生物/医学交叉学科论文汇报
- 配色柔和：米色/浅灰/淡绿 + 单一深色accent
- 适合有concept figure的论文（模型图/机制图）
- 谦逊感：不要用大号加粗标题，用轻量级排版

**提示词DNA**：
```
Taktram Japanese speculative design:
- Elegant concept prototypes and diagrams
- Soft tech aesthetic (rounded corners, gentle shadows)
- Charts and diagrams as art pieces
- Modest sophistication
- Neutral natural colors (beige, soft gray, muted green)
```

## 18. Kenya Hara - 空的设计

**哲学**：设计不是填充，是清空

**核心特征**：
- 极致的留白（80%+）
- 纸张质感的数字化
- 白色的层次（暖白、冷白、米白）
- 触觉的视觉化

**学术适配说明**：
- 最适合总结展望页和关键结果页
- 总结页：1-3句核心结论+大面积留白，不要列表堆叠
- 结果页：一张大Figure占80%画布+一句浮动解读
- 封面：论文标题+作者+期刊，周围留白≥60%

**提示词DNA**：
```
Kenya Hara "emptiness" design:
- Extreme whitespace (80%+)
- Paper texture and tactility in digital form
- Layers of white (warm white, cool white, off-white)
- Minimal color (if any, very desaturated)
- Design by subtraction not addition
```

| 论文类型 | 推荐风格 | 理由 |

| 生信方法论文 | Fathom + Müller-Brockmann | 数据驱动+流程清晰 |

| 综述论文 | Taktram + Pentagram | 概念优雅+信息架构 |

| 方法开发 | Müller-Brockmann + Fathom | 客观呈现+技术叙事 |
